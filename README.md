## REST API на собственном фреймворке без использования Express

###  Описание

В рамках лабораторной работы №6 был реализован REST API на базе самостоятельно разработанного фреймворка (ЛР5).  
Проект не использует сторонние фреймворки (Express и др.) — только `http`, `fs`, `url` и другие стандартные модули Node.js.

API работает с двумя сущностями: **эксперименты** и **учёные**, данные хранятся в `.json`-файлах.


###  Стек

- Node.js
- Собственный минималистичный фреймворк
- Без Express
- JSON как база данных


###  Структура проекта

project/ ├── index.js # Точка входа ├── framework/ # Фреймворк (Application, Router) ├── src/ │ ├── controllers/ # Обработчики маршрутов │ ├── services/ # Логика чтения/записи │ ├─ routes/ # Роутинг │ ├── db/ # JSON-файлы как БД + утилиты │ └── middlewares/ # (по необходимости)

###  особенности реализации
Используется собственный парсер body и query

Все данные сохраняются и обновляются в .json файлах

Проект построен по принципам: SOLID, KISS, DRY, YAGNI

Каждый слой приложения разделён: контроллеры, сервисы, роуты, база
